# Vayam (वयम्)

### For all of us.

Vayam is a multilingual civic intelligence platform built for the people of India.

It helps citizens discover government schemes, services, rights, opportunities, benefits, and important life-stage actions that are relevant to them — without forcing them to search through complicated government websites and scattered information.

Instead of asking:

> "What government schemes are available?"

Vayam asks:

> **"What matters to you?"**

## 🎯 The Problem

India has a vast ecosystem of government schemes, services, scholarships, benefits, rights, certificates, financial programs, educational opportunities, and civic services.

However, the information is often:

- Scattered across different portals
- Difficult to discover
- Written in complicated language
- Dependent on multiple eligibility conditions
- Difficult to understand for first-time users
- Available in different places for different states and departments
- Not personalized to the individual citizen

A student may be eligible for a scholarship but never know about it.

A citizen turning 18 may not know what new rights and responsibilities become relevant.

A working professional may not know about government financial or employment opportunities.

A senior citizen may not know which welfare programs apply to them.

The problem is therefore not simply:

> **"Lack of information."**

It is:

> **"Lack of personalized access to the right information at the right time."**

---

# 💡 The Solution

Vayam creates a personalized civic experience for every citizen.

A user provides relevant information such as:

- Date of birth
- State
- Education
- Student/employment status
- Income
- Other profile information

Vayam's Civic Intelligence Engine then processes this information and determines:

- Current age
- Life stage
- Important milestones
- Relevant government schemes
- Potential eligibility
- Upcoming opportunities
- Important civic services
- Relevant rights and information

The result is organized into:

### NOW
What matters to you right now.

### NEXT
What is approaching soon.

### LATER
What may become relevant in the future.

This turns government information into a **personal civic journey**.

A citizen doesn't necessarily think:

# 🧩 Rule-Based Eligibility Engine

Government schemes can have very different eligibility conditions.

One scheme may require:

```text
Age
+
State
+
Income
```

Another may require:

```text
Education
+
Student Status
+
Category
```

Another may have completely different requirements.

Vayam therefore uses a flexible rule-based architecture.

```text
Government Program
        ↓
Eligibility Rules
        ↓
Citizen Profile
        ↓
Rule Evaluation
        ↓
Eligibility Status
```

Possible states include:

```text
ELIGIBLE
NOT_ELIGIBLE
REQUIRES_VERIFICATION
UNKNOWN
```

---

# 🛡️ No Guessing

One of the core principles of Vayam is:

> **Never guess what the system does not know.**

If required information is missing, Vayam does not automatically assume a value.

For example:

```text
State = Missing
Education = Missing
Income = Missing
```

Instead of incorrectly saying:

```text
NOT ELIGIBLE
```

the engine can return:

```text
REQUIRES_VERIFICATION
```

along with the fields that are missing.

This is particularly important when dealing with government eligibility information.

# 🚀 Getting Started

## 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd Vayam
```

---

## 2. Install dependencies

```bash
npm install
```

---

## 3. Configure environment variables

Create a `.env.local` file.

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Add any additional AI or service keys required by the current implementation.

Never commit private API keys to GitHub.

---

## 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```
